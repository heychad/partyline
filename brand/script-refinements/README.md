# Script refinements

Chad selected Script and asked for its left-side mark to read more clearly as a phone or headset.

The four dialogue blocks, their placement, the palette, and the icon body are unchanged. Three alternatives replace the dots and connecting line:

- Receiver: a vertical phone receiver with blue and ochre ends.
- Angled receiver: the same receiver at a 12° angle.
- Headset: a telephone operator's headset.

Each folder contains the 1024 px PNG and editable SVG master, plus 128, 32, and 16 px PNG and SVG exports. All PNGs use sRGB and real transparency. Small versions use the master artwork without pixel-specific tuning.

These are refinements for review. The original concepts remain in `../round-1/`; no installed app assets have changed.
