# Angled receiver colorways

Nine colorways of Chad's selected angled receiver and dialogue blocks.

The receiver now reaches the bottom of the text blocks. A 64 px gap separates it from the blocks on the 1024 px canvas. All nine colorways share this revised layout; the text block shapes and sizes are unchanged.

Each numbered folder contains the editable `app-icon.svg`, `app-icon-1024.png`, and 128, 32, and 16 px SVG and PNG exports. PNGs have real transparency and sRGB profiles. The small exports use the master artwork without pixel-specific tuning.

`palettes.md` and `colorways.json` contain the exact colors. Earlier concepts remain in their existing folders. No installed app assets have changed.
